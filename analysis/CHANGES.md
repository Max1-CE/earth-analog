# Що змінено (чиста версія даних і метрики)

## Дані — один файл `sites.csv` (18 рядків)
- Злито `metrics/sites.csv`, `CSV_hak_MOON.csv` і `MAX_MARS.xlsx`. Інші версії більше не використовувати.
- Еталони Місяця, Гоутон, плато Девон, Фосгейм і Містастін — значення з `CSV_hak_MOON.csv` (найновіші).
- Додано долину Райта (MDV-WRI) з `MAX_MARS.xlsx`.
- Координати: Гейл → точка Curiosity (−4.59, 137.44), Езеро → точка посадки (18.44, 77.45).
- Висота Сонця перерахована для всіх точок за h = 90° − |φ| ± ε (ε: Земля 23.44°, Марс 25.19°, Місяць 1.54°).
  Виправлено помилку з від'ємним мінімумом (було: Гоутон −38.06°, правильно −8.82°; Малаперт +2.46°, а не −5.54°).
  Дно Шеклтона: максимум 0° (топографічна тінь), статус `topographic_shadow`.
- Класи порід приведено до назв з `rock_similarity.csv` (carbonate, sedimentary_clastic, impact_melt_breccia).
- Щільність кратерів — одна методика:
  Земля — 127 шт/10⁶ км² (одна ударна структура в радіусі 50 км) або 0; статус `estimate_1_within_50km`.
  Місяць — 45 000 для всіх трьох еталонів; статус `estimate_check_Robbins` (звірити з каталогом Robbins).
- Лід в Арктиці (Гоутон 0.3, Девон 0.3, Фосгейм 0.5) взято зі старої версії: у `CSV_hak_MOON.csv` стояло 0.01–0.02,
  що суперечить описам («масивний ґрунтовий лід»). Статус `test` — потрібне джерело.
- Фото й ліцензії для Марса, Намібії й Мак-Мердо перенесено з `MAX_MARS.xlsx`.

## Метрика — `metrics.py`
- Температура: порівняння в кельвінах через |ln(Ta/Tr)| / ln 3. Раніше для Місяця схожість завжди була 0.
- Лід: логарифмічна шкала (0.001…1). Раніше R = 0.5 робив «схожими» майже всі місця.
- Для еталонів Місяця автоматично сценарій `moon_base`, для Марса — `mars_landing`.
- Новий файл `ranking.csv`: рейтинг аналогів окремо для кожного еталона.
- Скрипт зупиняється з помилкою, якщо в даних є клас породи, якого немає в матриці.
