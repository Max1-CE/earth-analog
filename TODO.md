## 2. Статуси

- Для `relief_m` і `aridity_ai` немає колонки `status_*`, тому на сайті біля них немає значка.
  Потрібні `status_relief` і `status_aridity`, або ж явне рішення, що вони успадковують `status_slope`.

  і `topographic_shadow`. На сайті `estimate_*` показано сірим («placeholder»), а `topographic_shadow` —
  синім («computed»). Підтвердьте, що це правильно.

  На обидва значення стоїть один статус `topographic_shadow`.

## 3. Метрика (не помилка даних, але впливає на висновки)

- **MOON-MAL, рельєф:** `relief_m = 5000` при масштабі R = 1000 м дає `s_relief = 0` для **всіх**
  аналогів, тож критерій для Малаперта нічого не розрізняє.
- **Кратери Місяця:** при 45 000 / 10⁶ км² аналог із «1 структурою в радіусі 50 км» (127) отримує
  `s_craters = 0.49`, а аналог без неї — 0.07. Отже, цей критерій зводиться до «чи є поруч ударна структура».
- **Лід в Арктиці** (DEV-HAU, DEV-PLT, ELL-FOS) — статус `test`. Без джерела саме лід (вага 3 у `moon_base`)
  найсильніше впливає на рейтинг для Місяця.

## 4. Дрібниці

- `photo_license` записано по-різному: «public domain» / «Public Domain»,
  «Creative Commons Attribution 2.0 Generic license» / «…Generic». Варто уніфікувати.
- `photo_url` веде на сторінку файлу Commons, а не на зображення. Сайт сам перетворює посилання через
  `Special:FilePath`, тому тут нічого виправляти не треба. Просто майте на увазі, якщо дані будуть використовуватися деінде.
